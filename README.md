## 作品について

帝範の国字解。市川鶴鳴の『帝範国字解』で、唐の太宗が太子に与えた帝王の心得の書を、原文に国字の解を付けて収める。明治 44 年（1911 年）に早稲田大学出版部が『漢籍国字解全書』第 2 巻に収めたもの。OCR の柱から付けた見出しが付く（一部の篇は見出しに立てていない）。

## 底本

- [漢籍国字解全書 : 先哲遺著](https://dl.ndl.go.jp/pid/898775)（早稲田大学編輯部 編・早稲田大学出版部・1911年）。国立国会図書館の全文テキスト（OCR）のまま

国立国会図書館デジタルコレクションの「インターネット公開（保護期間満了）」の資料です。

## 本文の作り方

国立国会図書館デジタルコレクション（インターネット公開）の全文テキスト（OCR）をそのまま収めた。1 段落が底本の 1 コマ（見開き）。校正はしていないので、振り仮名や柱の混じり、読み違いが残る。
